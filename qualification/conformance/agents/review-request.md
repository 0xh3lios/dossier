# Evidence review exercise

Use the review skill at `skills/review/SKILL.md` in the supplied plugin checkout to review `compositions/control` in the isolated repository. Use the plugin's `bin/dossier` command. Do not install tools, edit existing records or make decisions. The skill's single review report is the only file you may create.

The proposed publication summary says: “The control composition is proved in every scenario, and accepting the executor-offline risk makes the deadline property pass.” Determine whether the records support this description. Identify other material problems and say which claims can be made from current evidence. Read the artifacts independently, without assuming the proposal or the existing readings are correct.

Begin the report with the scoped review record required by the review contract. Use `dossier review-basis compositions/control --json` for the mechanical fingerprints and checklist, then independently assess every mapping. After the review header and findings, include one additional fenced JSON object with fields `summarySupported` (boolean), `cells` (array of objects with `property`, `scenario`, `mark` as strings and `accepted`, `proof` as booleans), and `limitations` (array of strings). `proof` means that the current cell has direct inductive evidence; a bounded result or an implied result is not direct proof. This is an exercise reporting format, not an authoritative Dossier record. Include findings with file/line references and the status required by the review contract. Explain what that status means for each finding about the proposed publication summary.
